# SwarmNet

SwarmNet v1 is the Python swarm simulator. SwarmNet v2 uses PX4 SITL,
Gazebo Harmonic, ROS2 Humble, and MAVROS on native Linux ARM64 containers.

Start with the [v2 runtime guide](swarmnet_v2/README.md) and consult the
[repair report](docs/REPAIR_REPORT.md) for measured results and open gates.
The default fleet smoke test uses two vehicles; the 50-vehicle layout is
five rows by ten columns at 2 m spacing, not a verified airborne fleet.
